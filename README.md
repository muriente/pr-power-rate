# pr-power-rate

The current Puerto Rico (LUMA) residential electricity rate as a free public JSON endpoint, rebuilt hourly from
LUMA's official *Tabla de Factores de Ajustes* and verified digit-for-digit against the Energy Bureau (NEPR)
orders that set it.

**Endpoint:** https://muriente.github.io/pr-power-rate/api/v1/current.json
